# ShotShelf · 图架 1.0.8

1.0.8 修复图片篮子「导出所选」点击无响应，保留 1.0.0 至 1.0.7 的全部功能，界面布局不变。1.0.7 已修复的拖拽照片实时跟随鼠标完整保留。

## 本次修复

- **「导出所选」可正常点击并触发所选导出**：菜单打开时 `Menu` 会接管鼠标捕获，抬起事件无法到达「导出所选」项，而原先点击只负责展开子菜单，因此看起来毫无响应。现在在菜单根与该项两处用隧道阶段拦截按下，按可视树祖先链判断是否命中；已选中内容时点击直接触发所选图片的导出（弹出「选择导出位置」对话框），不再依赖子菜单是否弹出。
- 悬停仍可展开子菜单选择「打包为 ZIP」；「导出全部」「打开上次导出位置」行为不变。

## 范围说明

本次只改动导出菜单的点击处理与配套回归测试；导出逻辑、菜单布局、其它拖拽交互及 1.0.7 的拖拽跟随修复均未改变。1.1.0 计划中的坏图提示重试策略、批量清理性能、异常分类收窄与回收站配额等改进不在本版本内。

## 安装

1. 下载并完整解压 ShotShelf-1.0.8-windows-x64.zip。
2. 运行 Install.cmd，程序安装到 %LOCALAPPDATA%\Programs\ShotShelf。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

已有 1.0.0 至 1.0.7 用户可直接使用应用内更新，图片、设置和开机启动保持不变。需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 校验

发布页同时提供 .sha256 文件。可在 PowerShell 中执行：

    Get-FileHash .\ShotShelf-1.0.8-windows-x64.zip -Algorithm SHA256

将结果与 .sha256 文件中的值比较。
