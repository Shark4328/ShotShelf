# ShotShelf · 图架 1.0.4

1.0.4 将飞书、微信、QQ、`Win+Shift+S` 等剪贴板截图的到达动画与 `Ctrl+Alt+S` 内置截图统一。保留 1.0.0 至 1.0.3 的全部功能。

## 本次改进

- **统一到达动画**：剪贴板截图不再读取鼠标位置或创建独立飞行窗口，与内置截图一样执行货架展开、绳子回弹和卡片 0.16 秒淡入。
- **文件夹导入保留飞入**：`Win+PrtScn` 等保存到 Windows 截图文件夹的新图片仍从原位置飞入货架，鼠标位置只用于这一来源。
- **减少动画开销**：剪贴板到达不再创建额外顶层窗口和位图，连续截图时界面响应更稳定。

## 本次修复

- 飞书等剪贴板截图与内置截图动画不一致：前者多出 0.65 秒卡片飞行、弧线和落地淡出，后者只有货架展开与卡片淡入。
- 剪贴板到达时若卡片已被移除，直接索引字典可能抛出异常；现在改用 `TryGetValue` 防护并跳过飞入。

## 安装

1. 下载并完整解压 ShotShelf-1.0.4-windows-x64.zip。
2. 运行 Install.cmd，程序安装到 %LOCALAPPDATA%\Programs\ShotShelf。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

已有 1.0.0 至 1.0.3 用户可直接使用应用内更新，图片、设置和开机启动保持不变。需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 校验

发布页同时提供 .sha256 文件。可在 PowerShell 中执行：

    Get-FileHash .\ShotShelf-1.0.4-windows-x64.zip -Algorithm SHA256

将结果与 .sha256 文件中的值比较。
