# ShotShelf · 图架 1.0.2

1.0.2 是一轮收尾稳定性修复，保留 1.0.0 与 1.0.1 的全部功能。

## 本次修复

- **截图后恢复货架**：区域截图成功、取消或抓屏异常后，都会恢复到截图前的展开状态；隐藏等待超时仍会继续抓屏，不会让窗口永久隐藏。
- **截图落盘提示**：关闭自动挂图时，主动截图保存后会提示“已存入图片篮子”，并立即触发一次自动清理。
- **存储与清理更顺畅**：窗口改为可滚动布局，打开时先显示界面，再在后台统计截图占用；程序退出与清理重入使用不同提示。
- **导出失败可处理**：导出结束后保留结果文字，新增“查看失败详情”，可查看文件名与原因、复制清单，并使用仍存在的源文件重试。
- **重试不覆盖**：重试沿用原目标目录和导出格式，成功文件继续通过 name (2).ext 递增命名，不会覆盖已有文件。
- **临时文件清理**：每次导出前删除目标目录中超过 24 小时的 ShotShelf-导出-*.zip.tmp，未过期文件保留。
- **设置回滚**：保存清理设置失败时同步恢复开关、保留天数和阈值输入。

## 安装

1. 下载并完整解压 ShotShelf-1.0.2-windows-x64.zip。
2. 运行 Install.cmd，程序安装到 %LOCALAPPDATA%\Programs\ShotShelf。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

已有 1.0.0 或 1.0.1 用户可直接使用应用内更新，图片、设置和开机启动保持不变。需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 校验

发布页同时提供 .sha256 文件。可在 PowerShell 中执行：

    Get-FileHash .\ShotShelf-1.0.2-windows-x64.zip -Algorithm SHA256

将结果与 .sha256 文件中的值比较。
