# ShotShelf · 图架 1.0.5

1.0.5 是一轮稳定性与数据安全修复，保留 1.0.0 至 1.0.4 的全部功能，并统一了图片读取异常的处理方式。

## 本次修复

- **启动恢复不再被单张损坏图片中断**：此前 `data\Captures` 中只要有一张 0 字节或无法解码的图片，启动恢复就会停止，后面的图片无法回到图片篮子，同时弹出需要点击的模态错误框。现在逐张校验，坏图只记录 `error.log` 并跳过，其余图片照常恢复。
- **启动失败提示改为非阻塞**：真正无法启动的异常改用托盘气泡提示，数秒后自动退出，不再让常驻托盘程序停在无人察觉的对话框上。
- **文件夹导入的坏图不再静默卡住**：处理状态用 `try/finally` 保证释放；损坏图片记录一次日志并给出轻提示，不再被反复重试或留下无反馈的失败。

## 本次改进

- **自动清理改为移到回收站**：达到保留天数或存储阈值的旧文件现在会移到回收站，可恢复，与手动删除行为一致；删除前先确认文件未被占用，避免后台清理触发系统错误对话框。
- **统一异常策略**：启动恢复与运行期导入共用同一套「损坏图片」判定，同类异常不再分别表现为「弹框中断」与「静默跳过」。
- **空态提示跟随开关**：已开启剪贴板图片收集时，空货架不再提示「或开启剪贴板截图收集」。
- **文档澄清清理范围**：README 与更新记录说明启动时会把 `data\Captures` 中已有图片登记到图片篮子并纳入保护，因此保留天数主要作用于不在图片记录中的残留文件。

## 安装

1. 下载并完整解压 ShotShelf-1.0.5-windows-x64.zip。
2. 运行 Install.cmd，程序安装到 %LOCALAPPDATA%\Programs\ShotShelf。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

已有 1.0.0 至 1.0.4 用户可直接使用应用内更新，图片、设置和开机启动保持不变。需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 校验

发布页同时提供 .sha256 文件。可在 PowerShell 中执行：

    Get-FileHash .\ShotShelf-1.0.5-windows-x64.zip -Algorithm SHA256

将结果与 .sha256 文件中的值比较。
