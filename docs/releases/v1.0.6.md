# ShotShelf · 图架 1.0.6

1.0.6 是一轮文案与文档一致性修订，保留 1.0.0 至 1.0.5 的全部功能，不改变任何功能行为。

## 本次修复

- **清理结果文案不再称「释放空间」**：自动清理的文件已改为移到回收站，「存储与清理」窗口现在说明「已将 N 个文件移到回收站，可在回收站恢复；清空回收站后才会释放磁盘空间」，并保留移除数量与当前占用。此前 1.0.5 的窗口仍按永久删除显示「已删除 N 张截图，释放 X MB」，与 README 和发布说明矛盾。
- **清理窗口旧说明改正**：窗口内「删除的截图不会进入回收站」是 1.0.5 之前遗留的描述，现已改为「达到条件的旧文件会移到回收站，清空回收站后才会释放磁盘空间」。

## 本次改进

- **文档补充回收站占用说明**：README 的「自动清理」功能条目与常见问题明确「移到回收站的文件仍占用磁盘，清空回收站后才真正释放空间」，便于据此判断存储占用与数据可恢复性。

## 范围说明

本次仅落实 1.0.5 回测报告中列入 1.0.6 的一致性修复（C1 与 C3 的说明性文字），并同步版本号与相关测试断言。坏图提示重试策略、批量清理性能、异常分类收窄与回收站配额/清空入口等改进，按回测报告的版本安排延后至 1.1.0。1.0.5 已生效的六项优化行为保持不变。

## 安装

1. 下载并完整解压 ShotShelf-1.0.6-windows-x64.zip。
2. 运行 Install.cmd，程序安装到 %LOCALAPPDATA%\Programs\ShotShelf。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

已有 1.0.0 至 1.0.5 用户可直接使用应用内更新，图片、设置和开机启动保持不变。需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 校验

发布页同时提供 .sha256 文件。可在 PowerShell 中执行：

    Get-FileHash .\ShotShelf-1.0.6-windows-x64.zip -Algorithm SHA256

将结果与 .sha256 文件中的值比较。
