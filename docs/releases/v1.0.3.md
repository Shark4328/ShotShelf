# ShotShelf · 图架 1.0.3

1.0.3 主要解决挂图动画的卡顿，并补上图片篮子里的「复制所选」和导出菜单的鼠标点击。保留 1.0.0 至 1.0.2 的全部功能。

## 本次改进

- **恢复 GPU 渲染**：移除了主题初始化里强制整个进程使用软件渲染的设置，WPF 重新按系统与显卡能力选择渲染路径；硬件条件不足时仍由 WPF 自动回退。
- **动画只搬窗口，不重绘全屏**：飞行卡片把图片、白边、圆角和阴影一次性预渲染成冻结位图，窗口按卡片自身尺寸创建，不再为每张卡片铺满整个屏幕。
- **共享渲染循环**：同一批飞行共用一个 CompositionTarget.Rendering 循环，每帧只更新窗口位置、缩放、旋转和透明度，不再新建画刷、裁剪几何和阴影，也不修改宽高、边距或圆角。
- **消除每帧 UI 停顿**：逐帧移动窗口时抑制窗口位置变化消息，实测每次约 15 毫秒的 UI 线程占用降到 0 毫秒，篮子点击在动画期间也能立即响应。
- **复制所选**：图片篮子新增「复制所选」。单选时沿用原来的图片、PNG 与文件列表格式，可直接作为图片粘贴；多选时写入包含全部路径的多文件列表，在微信、QQ 等输入框一次粘贴即可批量发送。
- **导出菜单可点击**：「导出所选」「导出全部」标题行支持鼠标左键展开，并把焦点交给第一个子项；悬停与键盘操作保持不变。

## 本次修复

- 「导出所选」用鼠标点击没有反应，只能用悬停或键盘展开。
- 逐帧移动飞行窗口时触发的窗口位置变化消息导致动画期间界面卡顿、点击延迟。

## 安装

1. 下载并完整解压 ShotShelf-1.0.3-windows-x64.zip。
2. 运行 Install.cmd，程序安装到 %LOCALAPPDATA%\Programs\ShotShelf。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

已有 1.0.0 至 1.0.2 用户可直接使用应用内更新，图片、设置和开机启动保持不变。需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 校验

发布页同时提供 .sha256 文件。可在 PowerShell 中执行：

    Get-FileHash .\ShotShelf-1.0.3-windows-x64.zip -Algorithm SHA256

将结果与 .sha256 文件中的值比较。
