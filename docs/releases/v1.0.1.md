# ShotShelf · 图架 1.0.1

1.0.1 是一轮稳定性与数据安全修复，保留 1.0.0 的全部功能。

## 本次修复

- **与 PicRope 同时运行**：ShotShelf 改用专属的实例互斥体和消息窗口名，两个版本可以同时启动，`--quit` 只影响自身进程。
- **保护整个图片篮子**：自动清理不再只保护当前选中或预览的图片，篮子中的全部图片都会保留。桌面挂图、编辑器图片和外部原图继续排除在清理范围外。
- **ZIP 导出更可靠**：导出时先完整读取源文件，再写入压缩包；被占用或读取失败的文件只出现在失败清单中，不会生成空条目或残留临时文件。
- **启动失败可诊断**：初始化异常会写入 `error.log`，显示中文错误提示并退出，不再留下半初始化的托盘进程。
- **清理结果可见**：存储与清理窗口会显示删除数量、释放空间、当前占用和失败项；无法降到阈值时会说明受保护文件仍被保留。
- **更新包校验更完整**：解压后检查程序配置、WebView2 运行库和编辑器关键文件，缺失或为空时拒绝安装。

## 安装

1. 下载并完整解压 `ShotShelf-1.0.1-windows-x64.zip`。
2. 运行 `Install.cmd`，程序安装到 `%LOCALAPPDATA%\Programs\ShotShelf`。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

已有 1.0.0 用户可直接使用应用内更新，图片、设置和开机启动保持不变。需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 校验

发布页同时提供 `.sha256` 文件。可在 PowerShell 中执行：

```powershell
Get-FileHash .\ShotShelf-1.0.1-windows-x64.zip -Algorithm SHA256
```

将结果与 `.sha256` 文件中的值比较。
