# ShotShelf · 图架 1.0.0

ShotShelf 的首个独立版本。它把截图暂存在屏幕上沿，支持快速复制、拖拽、桌面贴图和图片篮子，并用独立品牌与原 PicRope 安装并存。

## 主要功能

- **截图收集与暂存**：监听 Windows 截图文件夹，也可从剪贴板或文件手动加入。
- **区域截图**：框选后直接标注，支持画框、圆形、箭头、画笔、文字、马赛克、撤销和重做。
- **桌面贴图**：图片置顶对照，滚轮缩放，点击图钉挂回绳子。
- **图片篮子**：多选挂图，导出所选或全部图片到文件夹或 ZIP；重名自动递增，不覆盖已有文件。
- **文字信封**：保存剪贴板文字，支持搜索、全文查看和复制。
- **本地编辑**：标注、文字、裁剪与旋转均在本机完成。
- **自动清理**：默认保留三天，达到 500 MB 阈值后从最旧截图开始清理，并保护当前使用中的图片。
- **桌面适配**：五套外观、多显示器、顶部悬停、开机启动和应用内更新。

## 安装

1. 下载并完整解压 `ShotShelf-1.0.0-windows-x64.zip`。
2. 运行 `Install.cmd`，程序安装到 `%LOCALAPPDATA%\Programs\ShotShelf`。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 从 PicRope 升级

ShotShelf 1.0.0 使用新的程序名、安装目录和数据目录，不会读取或迁移 PicRope 的数据。两个版本可以并存；如需保留旧截图，请先在 PicRope 中导出或另存。

## 校验

发布页同时提供 `.sha256` 文件。可在 PowerShell 中执行：

```powershell
Get-FileHash .\ShotShelf-1.0.0-windows-x64.zip -Algorithm SHA256
```

将结果与 `.sha256` 文件中的值比较。
