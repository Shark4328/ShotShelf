# ShotShelf · 图架 1.0.7

1.0.7 是一轮交互修复，保留 1.0.0 至 1.0.6 的全部功能，界面布局不变。

## 本次修复

- **「导出所选」可正常点击**：图片篮子「导出 → 导出所选」在已选中内容时，真实鼠标点击可能因菜单内部提前处理路由事件而收不到按下，或在抬起阶段被子菜单切换关闭。现在按下与抬起都可靠接收，点击后稳定停留在可选择导出格式的状态，可继续完成所选内容的导出；「导出全部」、悬停展开与键盘操作保持原样。
- **拖拽照片紧贴鼠标**：从顶部货架拖出照片时，预览改为由拖拽循环在每次鼠标移动时直接同步位置，不再依赖 25ms 的后台定时器；同时去掉每帧重算 DPI 与重设窗口尺寸带来的重绘，拖拽全程连续跟随，释放位置与指针一致。文件拖放的目标与载荷不变。

## 范围说明

本次只改动上述两处交互的事件处理与预览跟随，以及配套回归测试；导出逻辑、菜单布局、其它拖拽交互与 1.0.6 的文案一致性修复均未改变。1.1.0 计划中的坏图提示重试策略、批量清理性能、异常分类收窄与回收站配额等改进不在本版本内。

## 安装

1. 下载并完整解压 ShotShelf-1.0.7-windows-x64.zip。
2. 运行 Install.cmd，程序安装到 %LOCALAPPDATA%\Programs\ShotShelf。
3. 从桌面快捷方式或开始菜单启动 ShotShelf。

已有 1.0.0 至 1.0.6 用户可直接使用应用内更新，图片、设置和开机启动保持不变。需要 Windows 10 / 11 64 位和 .NET Framework 4.8。内置编辑器需要 Microsoft Edge WebView2 Runtime。安装包未签名，首次运行可能出现 SmartScreen 提示。

## 校验

发布页同时提供 .sha256 文件。可在 PowerShell 中执行：

    Get-FileHash .\ShotShelf-1.0.7-windows-x64.zip -Algorithm SHA256

将结果与 .sha256 文件中的值比较。
